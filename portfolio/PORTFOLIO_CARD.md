# DocSight AI — Smart Document Classifier & Summarizer

Python • FastAPI • scikit-learn • React • PDF/NLP

A document analysis application that predicts document categories using a synthetic-trained TF-IDF model and returns extractive page-cited summaries, with React upload tools, metadata-only SQL analytics, CI and Docker.

[GitHub source](https://github.com/harshakavali81-collab/Smart-Document-Classifier-Summarizer) and [case study](../docs/PORTFOLIO_CASE_STUDY.md).

Disclosure: six synthetic-trained document categories; not validated on real production documents or deployed as an authenticated SaaS.
